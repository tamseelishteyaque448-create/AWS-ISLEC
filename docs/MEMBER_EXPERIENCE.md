# Member experience

The member journey is intended to be **Discover -> Join -> Learn -> Build -> Connect -> Contribute -> Prove -> Lead**.

Public visitors can browse home, about, explore, learn, events, projects, and join/login. Authenticated members use profile, journey, learning/challenges, events, project discovery/details, My Projects, activities, achievements, and leaderboard routes.

The current active phase (Projects V2.3) covers published-project discovery, relationship-aware project detail, join-request states, optional skill proofs, owner review, accepted membership, My Projects, workspace entry, and empty/loading/error/archived/shipped/recruitment/capacity presentation. The source contains these surfaces, but authenticated browser behavior and responsive runtime behavior are **NOT VERIFIED**.

Learning completion and event attendance feed activities, points, badges, and stages. Project participation contributes evidence under database rules. Historical membership evidence is progression evidence, not a workspace permission.
