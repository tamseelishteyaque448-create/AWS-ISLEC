# Changelog context

Use [docs/CHANGELOG.md](../docs/CHANGELOG.md) for the maintained history. It records only decisions recoverable from migrations, source, and git history.

Status discipline:

- **IMPLEMENTED:** present in checked-in source.
- **VERIFIED:** backed by an executed command or runtime check.
- **NOT VERIFIED:** source/configuration exists, but execution or live parity evidence is absent.
- **PLANNED:** approved scope not yet implemented.
- **BLOCKED:** cannot safely proceed until a dependency or decision is resolved.

The current active phase is Projects V2.3. Do not treat old phase notes, historical QA claims, or source migration presence as proof of live deployment behavior.
